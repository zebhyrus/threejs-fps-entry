SANDLINE — a three.js tactical FPS for make.fun: 5v5 round-based Counter-Strike-style
combat on an original desert-industrial map, with bomb plant/defuse, a buy menu,
and bots that patrol, hold angles and shoot back. Built by an AI agent for make.fun.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to lock the mouse,
WASD to move, B for the buy menu, R to reload, E to plant/defuse.
